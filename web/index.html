versión …

Muestra frecuencia, modo, banda, S-meter, potencia y SWR, y desde la pantalla táctil cambia modo, banda, frecuencia, VFO, split, clarificador y tonos de repetidor. Se conecta a la radio por cable (adaptador de nivel) o por Bluetooth con un adaptador CAT tipo HC-05/HC-06.

Instalar o actualizar

  1. Usa Chrome o Edge en un ordenador (la instalación usa Web Serial; no funciona en Safari, Firefox ni en el móvil).
  2. Conecta la placa con un cable USB de datos (muchos cables sólo cargan).
  3. Pulsa Instalar en tu variante y elige el puerto (CH340, usbserial o COMx).
¿Sale «Failed to initialize» o la pantalla parpadea sin grabar?

El instalador no consigue poner la placa en modo de grabación (pasa a menudo con el chip CH340). Hazlo a mano con el botón BOOT, junto al conector USB:

  1. Mantén pulsado BOOT, pulsa Instalar y elige el puerto.
  2. Suelta BOOT cuando empiece a avanzar el porcentaje.
  3. Si no entra: con BOOT pulsado, pulsa y suelta RST y luego suelta BOOT; después pulsa Instalar.
  4. Al terminar, pulsa RST si no arranca sola.

Cierra antes cualquier otro programa que use el puerto (monitor serie, terminales, el simulador).

¿Colores raros (fondo blanco, amarillo azulado)? No reinstales: MENU → Ajustes → Pantalla → Colores Normal / Invertidos.

Al actualizar se conservan los ajustes, la calibración del táctil y el emparejamiento Bluetooth. Si el instalador pregunta, marca borrar sólo en la primera instalación o si algo falla.

Pruebas sin radio (CAT por el USB)

El CAT va por el propio cable USB para usar el simulador del ordenador (tools/ft8x7_sim.py). No conectar a una radio.

Primeros pasos

  1. MENU → Ajustes → Radio: elige tu modelo.
  2. Enlace por cable: elige los baudios iguales al menú CAT RATE de la radio (FT-817/818: menú 14; FT-857: menú 019, y el menú 020 en CAT).
  3. Enlace por Bluetooth: Ajustes → Enlace Bluetooth → Buscar → toca tu adaptador. PIN por defecto 1234. Pon el CAT RATE de la radio igual que el adaptador (normalmente 9600). Después se reconecta solo.
  4. Si el táctil no acierta: Ajustes → Pantalla → Calibrar táctil.
